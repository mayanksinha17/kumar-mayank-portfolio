# Add your resume here

Every "Download Resume" button on the site links to `/resume.pdf`.

To make those buttons work:

1. Export your actual resume as a PDF.
2. Name it exactly `resume.pdf`.
3. Drop it in this `public/` folder (same level as this file).
4. Delete this placeholder file — it's just a reminder and isn't linked anywhere.

No resume content was invented anywhere on this site. Skills, education, and
project details were pulled from what you provided and from your public
GitHub repository — the resume file itself has to come from you.
